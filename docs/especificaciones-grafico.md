# Especificaciones del método gráfico

## Que entra a la lógica
 Nombres de las variables y Nombre del problema (opcional)- Coeficientes de la función objetivo - Especificación de maximización o minimización - Restricciones a las que está sujeta la función - Desde 1 hasta 8 restricciones(Elección de cuántas desde un inicio) - Cada restricción despliega una lista para elegir que tipo de restricción

## Supuestos
 Restricciones de no negatividad: X1, X2 >=0
## Operadores
 Se usarán 3: <=,>=, =

## Validaciones Relacionadas al método
 Al hacer todo el cálculo y las evaluaciones, se muestra como resultado: 1. Óptimo único especificando cuanto vale cada variable, demostrando que cumple todas las restricciones y mostrando el gráfico. 2. Óptimos alternativos despliega por cada opción lo mismo que muestra el óptimo único. 3. Infactible Expresa que las restricciones son mutuamente excluyentes y que no tienen espacio común, diciendo que se evaluaron los puntos de cruce en las restricciones pero que ninguno cumple todas las restricciones al tiempo. 4. No acotado le dirá al usuario que las restricciones permiten que la función objetivo se crezca indefinidamente.

 Grafico - Tabla de puntos evaluados - Solucion - Sensibilidad - Factibilidad - Caso del problema
